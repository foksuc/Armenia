# Armenia Travel OS
Personal Russian-language dashboard for a two-person Armenia trip, 13–18 February 2027. Existing repository supplies itinerary, booking URLs and historical prices checked 24 October 2026. Primary user prepares on desktop and checks plans on Android. Preserve original files and main. Build in v2 on a separate branch. User pins Glassmorphism inspired by Glassy Dashboard V5; no vendor source available. Browser-local expenses and booking state must remain compatible. New functionality: linked day/map view, searchable places, preparation checklist and daily notes. Assumption: no backend, paid API or live pricing is needed.
