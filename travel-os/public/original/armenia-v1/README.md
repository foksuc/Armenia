После включения GitHub Pages: https://foksuc.github.io/Armenia/

## Включить GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, затем ветку **main** и папку **/ (root)**. Нажмите **Save**. GitHub покажет адрес публикации на той же странице после завершения сборки.

## Файлы

- `style.css` — оформление.
