# ATLAS / 27 — шесть путешествий

Статический сайт с каталогом поездок на 13–18 февраля 2027 года: Армения, ОАЭ, Оман, Азербайджан, Узбекистан и Казахстан. Оригинальный маршрут Армении находится по адресу `/armenia/`.

## Открыть сайт

После включения GitHub Pages: https://foksuc.github.io/Armenia/

Если ссылка не открывается, в репозитории перейдите в **Settings → Pages** и выберите **Build and deployment → Deploy from a branch → main → /(root) → Save**. После публикации обновите страницу через несколько минут.

## Данные

Цены и наличие билетов не обновляются автоматически. Ссылки ведут к поиску Trip.com с датами 13–18 февраля 2027 и рублёвой валютой; тариф надо проверить перед оплатой. Цена на карточке отеля — ориентир за ночь по отелю, а не стоимость нужной категории и пяти ночей. Время работы и экскурсии могут измениться.

Сайт работает без сборки: `index.html`, `trip.html`, `catalog-data.js`, `catalog.js`, `catalog.css` и папка `armenia/`.
